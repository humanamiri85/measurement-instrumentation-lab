# شواهد اعتبارسنجی فصل ۴

محیط: Node.js 24، Chromium نصب‌شده در `/usr/bin/chromium`، Playwright 1.58.2، axe-core 4.11.1 و SciPy 1.17.0 برای ممیزی مستقل آفلاین. هیچ وابستگی اجرایی جدید اضافه نشده است.

| بررسی | نتیجه |
|---|---|
| `npm test` | ۱۳۰ آزمون موفق، صفر شکست؛ ۴۰ آزمون موجود بدون تغییر و ۹۰ آزمون فصل ۴ |
| ممیزی مستقل بانک | ۸۱ سناریوی عددی از ۸۲ مورد با NumPy/SciPy مقایسه شده‌اند؛ مسئلهٔ مفهومی ۴٫۱۱ پاسخ عددی ندارد |
| توزیع‌ها | مقدارهای مستقل CDF نرمال، t، χ² و کوانتایل‌های t/χ²، نه صرفاً CDF در برابر معکوس خودش |
| آزمون مرورگر فصل ۲ | ۹۲ ترکیب چیدمان، کنترل‌ها و دسترس‌پذیری؛ موفق |
| آزمون مرورگر فصل ۳ | ۲۸ ترکیب چیدمان، کنترل‌ها و دسترس‌پذیری؛ موفق |
| آزمون مرورگر فصل ۴ | ۹۶ ترکیب مسیر/عرض صفحه، تمام کنترل‌ها، بازنشانی‌ها و ناوبری؛ موفق |
| عرض‌ها | ۱۴۴۰، ۱۲۸۰، ۷۶۸ و ۳۹۰ پیکسل |
| بانک تمرین در مرورگر | همهٔ ۸۲ شناسه، صفحهٔ منبع، راهنماها و نمایش حل؛ پاسخ غلط و توافق عددی، جست‌وجو و بارگذاری داده |
| حالت‌های نامعتبر | عدد خالی، متن غیرعددی، دادهٔ نامعتبر، شمارش ناکافی آزمون برازش، حذف بدون دلیل، n<2، پراکندگی صفر و مخرج صفر |
| تحقیق فشار و AI | جلوگیری از ثبت تکمیل بدون شواهد؛ حفظ نقدهای جداگانه با تغییر ادعا؛ عدم ارزیابی خودکار استدلال |
| ذخیره و خروجی | ماندگاری یادداشت/پیشرفت پس از reload، بازنشانی، خروجی JSON و محتوای واقعی فایل، fallback خرابی localStorage |
| دسترس‌پذیری | axe WCAG 2 A/AA و 2.1 A/AA در تمام ۹۶ چیدمان فصل ۴؛ بدون نقض گزارش‌شده |
| گرافیک و شبکه | بدون مختصات NaN/Infinity، بیرون‌زدگی صفحه یا بریدگی نمودار، خطای console، page یا درخواست |
| مسیرهای نسبی | آزمون فصل ۴ زیر پیشوند نام مخزن اجرا می‌شود، مطابق میزبانی زیرپوشه‌ای GitHub Pages |

تصاویر دسکتاپ و موبایل به‌صورت دیداری بازبینی شده‌اند. محور QQ پس از بازبینی روی دامنهٔ داده اصلاح شد؛ سناریوی پیش‌فرض برازش ۱۰۰ دادهٔ تکرارپذیر دارد و p معتبر نشان می‌دهد. تصاویر منتخب برای مرور تغییر:

همهٔ تصاویر تولیدی با اجرای آزمون در `test-results/` قرار می‌گیرند؛ فقط تصاویر منتخب در مستندات نگه داشته شده‌اند. PDF یا تصاویر صفحات منبع در مخزن قرار نگرفته‌اند.

این نتایج آزمون‌های پیاده‌سازی و دسترس‌پذیری خودکارند، نه تأیید آماری هر فرایند واقعی. محدودیت‌ها: آزمون برازش با ادغام/مرزهای وابسته به داده یک تشخیص مجانبی آموزشی است؛ استنباط دقیق به طرح از پیش مشخص یا bootstrap نیاز دارد. فاصله‌های دقیق به نرمال بودن و استقلال وابسته‌اند. مدل فشار کم‌سرعت است و عدم‌قطعیت مرجع اعتبارسنجی در سناریوی ساده لحاظ نشده است. صورت‌های مبهم فقط تحت اصلاحات آشکار محاسبه شده‌اند؛ استدلال‌های نوشتاری نیازمند بازبینی مدرس هستند.
